# AI DataWave — 12‑Hour AI Workshops & Hackathon

**When:** 24–25 February 2024  
**Format:** Online — in collaboration with GDSC FSB  
**Organised by:** GDSC SupCom & GDSC FSB

Join a hands‑on, 12‑hour journey into AI and machine learning featuring practical workshops and an exciting hackathon. Whether you’re starting out or looking to sharpen your skills, expect interactive sessions, real‑world tips, and networking with peers.

## Highlights
- Interactive workshops covering foundational and advanced AI topics  
- Hackathon to apply what you learn in a collaborative, competitive setting  
- Practical demos, code examples, and Q&A with industry-savvy speakers

## Speakers & Topics
- **Amel Sallemi** — Time Series Forecasting Techniques  
- **Hafedh Hichri** — Introduction to Using Pretrained LLMs  
- **Imen Masmoudi** — KerasCV (Computer Vision with Keras)  
- **Nourchene Ferchichi** — Fundamentals of Deep Learning  
- **Imen Selmi** — Clustering Algorithms and Applications  
- **Oumaima Aouadi** — Introduction to Generative AI  
- **Eya Laouini** — Sentiment Analysis with Machine Learning  
- **Maryem Aloulou** — Data Extraction Techniques  
- **Hamdi Ouardi** — Leveraging AI for Enhanced Cybersecurity
